\## Week 1 Highlights



\### Development Environment



\- Installed and verified the .NET SDK.

\- Configured Visual Studio and Visual Studio Code.

\- Created and ran the first C# console application.



\### C# Fundamentals



\- Practiced value types and reference types.

\- Used variables, type inference, naming conventions, control flow, and nullable reference types.

\- Demonstrated value-copy and reference-copy behavior.

\- Created a grade classifier using a switch expression.



\### Object-Oriented Programming



\- Created related classes for an order-management domain.

\- Applied fields, properties, constructors, encapsulation, records, interfaces, and polymorphism.

\- Validated product availability and reduced stock after successful orders.



\### Collections and LINQ



\- Used `List<T>`, `Dictionary<TKey, TValue>`, and `HashSet<T>`.

\- Applied filtering, projection, ordering, and aggregation using LINQ.

\- Used LINQ Method Syntax and Query Syntax.

\- Practiced `async`, `await`, `Task.Delay()`, and exception handling.
